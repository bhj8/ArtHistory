# 网站优化任务清单

## 第一轮

- [x] 1. 核心内容：补足地域、人物、代表作品、历史影响，采用事实陈述。
- [x] 2. 代表作品：逐条精选核心条目的图片，补齐不足并保留出处与授权。
- [x] 3. 词条跳转：正文中的已有概念可直接打开，保留阅读返回路径。
- [x] 4. 图像对照：自由选择两件作品，并排查看、分别放大和移动。
- [x] 5. 搜索：别名、中英文、拼写提示，分组显示条目、人物和作品。
- [x] 综合验证：数据、自动检查、桌面和手机实际操作、返回位置回归。

验证记录：233 个条目、660 幅图片、42 个核心条目、128 个精选位置；中英文人物搜索、错字建议、正文跳转与返回、左右独立缩放和拖动、手机布局均实测。列表在纵向 6527 px 处打开条目并切图，关闭后仍为 6527 px。

## 第二轮：检索与全局视角

- [x] 搜索：学习路线页每次输入只查询一次（原先每条路线的每站各查一次，连打 4 个词约 300 ms，现约 10 ms）；等拼音输入法选完字、停顿 160 ms 再查询；聚焦搜索框即预载索引；搜索覆盖全部条目，不受“核心”范围限制。
- [x] 快速检索：`/` 或 `Ctrl/⌘ + K` 打开下拉，条目、人物、作品分组，键盘选择、回车打开；空白时显示最近读过与随手翻翻。
- [x] 人物页：225 位人物，含生卒年与身份说明；过滤“作者不详”、工坊、追随者等非人物署名，多人署名分别归入；可用 `#person=` 链接分享。
- [x] 时间轴：233 个条目补充 `years`，按分类排出大致活跃期，可放大单个时代；详情页新增“同一时期的其他地区与领域”。
- [x] 界面：筛选区合并为一行，手机端改为两个下拉，首屏内容区上移；全景地图在 1440 px 宽度下完整显示 7 个时代。
- [x] 个人使用：条目笔记；收藏、笔记与阅读记录导出/导入 JSON；收藏与最近读过不受“核心”范围隐藏。
- [x] 深色模式（跟随系统或手动切换），可添加到主屏幕，离线时可阅读已打开过的条目与图片。

## 第三轮：切换时代

先用六个角度（桌面地图、时间轴、手机、其他视图、内容数据、用户任务）在 1024—1920 px 和 360—768 px 下实测，73 条问题逐条复核后修复。

- [x] 单个时代不再把 7 列表格拉成一列：改为按分类的图卡，显示本时代全部条目（原先每格只显示 5 条），并列出仍在延续的更早传统和尚未收录的分类；桌面、平板、手机同一布局。
- [x] 时代导览：上一/下一时代及其条目数、时代概述、“核心 N 条 · 全部 M 条”提示与一键显示全部；长列表底部再给一次，键盘 `[` `]` 切换。
- [x] 全景地图：1000 px 起 7 个时代完整显示，时代表头滚动时停在页头下方；去掉对全部条目都成立的“有配图”图标，节点高度减半；核心范围的空格提示“全部范围有 N 条”。手机的时代标题可直接“只看此时代”，折叠分组显示前几个条目名。
- [x] 时间轴：放大的时代按容器宽度铺满（原固定 1100 px，笔记本上溢出、宽屏留白、手机只见四分之一）；本时代条目一律画出，横跨整个时代的长期传统改为“贯穿本时代”标签；空分类保留并说明原因；右端标签不再溢出，延续到下一时代的条形标“→”；年代轴随页面滚动吸顶；缩小回全部时代时回到刚才的位置；关闭条目后保留横向位置。
- [x] 数字一致：分类、时代、核心/全部旁的数字随其他筛选变化；时间轴条数与条目数一致；空结果按时代、范围、分类给出有内容的去处，搜索加时代筛选不再无路可退。
- [x] 浏览器返回：切换视图、分类、时代可以用“返回”退回；键盘操作后焦点留在原控件；“再显示更多”随筛选重置。
- [x] 作品图库按作品自己的年代（627 件已标注）归入时代并按年代排序，全部时代时分段标题；学习路线在时代筛选下标出落在这一时期的站点。
- [x] 年代检索：`1500`、`16世纪`、`前5世纪`、`1960年代`、`1400—1500` 等。
- [x] 内容：魏晋南北朝、格拉斯哥风格、城市景观画、画意摄影、扬州八怪等条目的时代或年份与史实对齐，修正十余处与年份矛盾的日期文字；新增时代归属一致性检查。
- [x] 第二轮复核（65 条）后的修正：图库和学习路线的计数改用“幅”“条路线”，路线不再受核心范围影响；全部时代图库的时代标题不再来回跳；“同期并存”标出更早起源（←），只有延续到今天的传统才写“今”；关闭条目、人物页后“返回”不再原地踏步，图片大图等浮层先被“返回”关闭；年代检索支持“约1500年前后”“20世纪60年代”“1500s”等写法，在世艺术家、“活动于某世纪”的人物也能按年代找到；拉斐尔不再误连到拉斐尔·洛萨诺-赫默；手机下拉框显示数量；深色模式分类文字对比度达标。
