# 网站优化任务清单

## 第一轮

- [x] 1. 核心内容：补足地域、人物、代表作品、历史影响，采用事实陈述。
- [x] 2. 代表作品：逐条精选核心条目的图片，补齐不足并保留出处与授权。
- [x] 3. 词条跳转：正文中的已有概念可直接打开，保留阅读返回路径。
- [x] 4. 图像对照：自由选择两件作品，并排查看、分别放大和移动。
- [x] 5. 搜索：别名、中英文、拼写提示，分组显示条目、人物和作品。
- [x] 综合验证：数据、自动检查、桌面和手机实际操作、返回位置回归。

验证记录：233 个条目、660 幅图片、42 个核心条目、128 个精选位置；中英文人物搜索、错字建议、正文跳转与返回、左右独立缩放和拖动、手机布局均实测。列表在纵向 6527 px 处打开条目并切图，关闭后仍为 6527 px。

## 第二轮：检索与全局视角

- [x] 搜索：学习路线页每次输入只查询一次（原先每条路线的每站各查一次，连打 4 个词约 300 ms，现约 10 ms）；等拼音输入法选完字、停顿 160 ms 再查询；聚焦搜索框即预载索引；搜索覆盖全部条目，不受“核心”范围限制。
- [x] 快速检索：`/` 或 `Ctrl/⌘ + K` 打开下拉，条目、人物、作品分组，键盘选择、回车打开；空白时显示最近读过与随手翻翻。
- [x] 人物页：225 位人物，含生卒年与身份说明；过滤“作者不详”、工坊、追随者等非人物署名，多人署名分别归入；可用 `#person=` 链接分享。
- [x] 时间轴：233 个条目补充 `years`，按分类排出大致活跃期，可放大单个时代；详情页新增“同一时期的其他地区与领域”。
- [x] 界面：筛选区合并为一行，手机端改为两个下拉，首屏内容区上移；全景地图在 1440 px 宽度下完整显示 7 个时代。
- [x] 个人使用：条目笔记；收藏、笔记与阅读记录导出/导入 JSON；收藏与最近读过不受“核心”范围隐藏。
- [x] 深色模式（跟随系统或手动切换），可添加到主屏幕，离线时可阅读已打开过的条目与图片。
