# 配图文字审查：第二批

范围为 `Object.keys(data/artworks.json).sort().slice(220, 440)`，共 220 个唯一记录，从 `cma-150488` 至 `commons-79699321`；逐件审阅完整本地元数据和 135 个相关条目的年代、地域、背景及媒介，共检查 260 条原有关联。JSON 的 `reviewedEntries` 保存此次读取时的关联。

本轮不看图片。`consistent` 表示作品名称、作者、年代、媒介等文字信息与关联条目相容，不表示图片像素、所有图注细节、版权或全部馆藏记录均经外部验证。外部查证只针对疑点及若干易误删的关系；`sources` 仅列实际查看的来源。

结果：213 件文字归类相容，5 件建议修正，2 件含不确定关联。

明确修正：

- `cma-151358`：商代玉戈材质是软玉，改归玉器；标题明确为玉戈。商代年代并不能使玉器成为青铜器实例。
- `cma-155863`：大理石容器被说明误写成陶器；保留史前关联并改材料表述。
- `cma-159880`：权贵帽是纤维服饰，改归纤维与织物；不是 nkisi 力量像。
- `cma-168739`：刚果基督十字架改归广义非洲雕刻；不能仅凭刚果地域归入特定的力量像类型。
- `commons-26247205`：《泉》保留达达与观念关联，观念关联明确为前驱及后来的再制作版本。

保留的不确定性：

- `cma-151346`：馆方本就写“米斯特克或阿兹特克”。可以保留阿兹特克条目中的对照资料，但需在中文图注直接标明归属未定。
- `commons-76412409`：《同理心》可留后现代艺术；本轮未找到该作女性主义具体主题的原始依据，建议移除女性主义关联，不能由艺术家整体身份代替对该作的判断。

明确不应误删的关系：

- 明代中国制曼荼罗基座与刺绣唐卡，馆方明确具有藏传佛教用途，喜马拉雅关联成立。
- 昂格朗《收获结束》虽是黑白炭笔，馆方明确说明其技法与点彩、分色主义关系，新印象主义关联成立。
- 卡梅伦早于画意摄影运动制度化，是其前史；艺术运动的概括年代不应机械作为作品排除线。
- 后世展照、复制版本、同作整体与局部不等于分类错误；文件逐件区分作品年代和照片年代。

审查记录文件仅提出建议；是否已应用修正应查数据变更与主任务验收结果。
