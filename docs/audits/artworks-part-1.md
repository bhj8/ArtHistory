# 配图文字归类审核：第 1 组

范围为审核开始时 `Object.keys(artworks).sort().slice(0, 220)`：从 `abstractexp` 至 `cma-150420`，共 220 件作品、280 条条目关联。`reviewedEntries` 与本轮修改前 Git HEAD 的关联一致。

逐件核对了作品题名、作者或文化归属、年代、媒介、已有注释，以及每一个关联条目的地区、时间和主题范围。本轮未加载图片，也没有把所有馆藏网页重新查一遍。JSON 中 `sources` 仅填写实际阅读过的官方记录；空数组表示结论来自本地文字元数据与条目背景的一致性检查，不代表馆方重新认证。

结果：208 件文字归类一致，10 件建议修正，2 件须保留不确定性。`consistent` 不等于完成真伪、版权、图像与元数据对应关系的鉴定。

## 保留的不确定性

- `cma-123985`：馆方同时使用塞尔柱文化标签及1200—1221年断代。文字可说明文化传统与政权年代的区别，不能根据本站概括年份自行改定王朝。伊斯兰书法关联明确成立。
- `cma-128191`：馆方仅定为奇穆或印加文化。保留这个不确定归属，不把“或”改成已确定的印加；中文动物名称建议采用美洲驼。

时代、作者后期延续、媒介和题材是不同维度。已有明确事实说明的历史前例、后制织物、仿古家具、跨媒介关联未被机械删除。
