# 内容维护说明

## 知识条目

在 `data/entries/` 中选择 `west`、`china`、`asia`、`world`、`design` 或 `media` 文件。每个条目必须包含：

| 字段                  | 用途                                                          |
| --------------------- | ------------------------------------------------------------- |
| `id`                  | 稳定的小写英文 ID，用于链接、收藏、路线与关联；发布后不要更名 |
| `lane` / `era`        | 分类 ID 与时代索引，定义在 `taxonomy.json`                    |
| `zh` / `en` / `date`  | 中英文名称和概略时期                                          |
| `kind` / `hook`       | 条目类别、一句话定义                                          |
| `look` / `idea`       | 视觉特征和核心问题                                            |
| `people` / `work`     | 人物、作品与观察建议                                          |
| `distinguish`         | 容易混淆的概念                                                |
| `tags`                | 空格分隔的补充搜索词                                          |
| `source`              | 主资料的来源 ID，未核实则留空                                 |
| `sources`             | 可选的其他来源 ID 数组                                        |
| `context` / `reading` | 可选的历史背景、观看要点；支持字符串或段落数组                |

保持概念层级清楚：流派、时代、地区、技法、机构不等价。不要为了增加条目数而重复定义。时期是导航坐标；它不表示一项传统只存在于一个时期。

## 作品图库：一条目多作品，一作品可关联多条目

`data/artworks.json` 的键现在是**作品 ID**，不再要求与条目 ID 相同。旧作品 ID 保留，以便保持已有路径稳定。例子：

```json
{
  "met-436535": {
    "oid": 436535,
    "entries": ["postimp"],
    "zh": "有柏树的麦田",
    "title": "Wheat Field with Cypresses",
    "artist": "Vincent van Gogh",
    "artistZh": "文森特·梵高",
    "date": "1889",
    "museum": "The Met",
    "url": "https://www.metmuseum.org/art/collection/search/436535",
    "credit": "原始馆藏署名",
    "publicDomain": true,
    "image": "assets/artworks/met-436535.webp",
    "width": 1200,
    "height": 953
  }
}
```

1. 先核对馆藏标题、作者、年代、题材与归属，再关联条目。专题里的作品可能是前代对照材料，不能整页自动归类。
2. 图片保存为独立 WebP，长边通常 1000—1600 像素，单张小于 2 MB。尺寸填写实际尺寸，帮助浏览器预留布局。
3. 同一作品共用一条元数据，通过 `entries` 关联多个条目，不复制图片。
4. 中文标题可以意译，但保留原题。年代、作者归属有争议时保留限定语。
5. `publicDomain` 按馆方记录填写。网页可访问不代表公共领域；仓库不替图片统一授予许可。
6. 新增开放图片保存 `metadataSource`、`sourceImage`、`license` 与 `licenseUrl`，方便复核。本轮克利夫兰艺术博物馆图片由官方 API 的 `share_license_status: CC0` 筛选；不把搜索结果直接按关键词归类。
7. `artist` 保留原始作者信息和 `attributed to`、`follower of`、`studio of` 等限定；`artistZh` 是界面上的中文导读署名。共同创作者、题字者和设计者应分别标明。
8. `notes` 可按关联条目 ID 保存具体观看提示，例如 `"notes": { "cyanotype": "观察植物的白色轮廓与蓝色感光背景。" }`。背景材料、习作和跨地域对照须明确说明，不能当作流派的典型原作。

加载器自动建立条目—作品索引。图库分页渲染，图片懒加载；条目详情提供缩略图切换和大图前后翻阅。

图解词典在卡片中显示最多三张补充作品预览，点击时保持当前条目上下文；最近阅读沿用原本的本地阅读记录，最近重新打开的条目排在前面。只看有图筛选保存在网址参数中，可以分享。大图提供放大和滚动查看，原始馆藏链接用于进一步研究。

截至本轮，523 件作品覆盖 157 / 233 个条目，其中 136 个条目有多图。剩余 76 个条目主要集中在战后当代艺术、设计与数字媒介。后续应优先寻找这些领域中出处与权限清楚的实例；不以无关图片或仿作填满空白。

## 关系、路线与来源

- `relationships.json` 每项为 `[起点ID, 终点ID, 关系类型, 解释]`。先区分影响、延续、形式比较、共同媒介；不能只凭相似声称历史因果。
- `routes.json` 的 `ids` 是建议阅读次序；所有 ID 必须存在，不重复。
- `sources.json` 保留来源的 `zh`、`title`、`url`、`org`。资料必须是实际核实的页面。检索链接由界面单独生成，不作为已核实来源。

## 改代码的位置

- `src/content.js`：读取 JSON，建立检索和多图索引。
- `src/ui/views.js`：地图、目录、图库、路线。
- `src/ui/detail.js`：条目阅读和对照面板。
- `src/ui/helpers.js`：转义、图片及链接组件。
- `src/main.js`：筛选、网址状态、收藏、弹窗与导航事件。
- `src/storage.js`：稳定的本地收藏键名。
- `src/styles/main.css`：桌面与窄屏布局。800 px 以下地图改为时代分组。

## 提交与验收

运行 `npm run build`。校验会检查条目、关联、路线、作品归属、中文标题、来源引用、图片格式和大小、JavaScript 语法。再实际检查：搜索人物及作品名、多条件筛选、无结果与重置、多图切换、收藏持久化、对照、路线前后跳转、浏览器后退、键盘关闭以及窄屏布局。

`main` 提交自动部署；PR 只校验。`dist/` 为生成物，不提交。未来扩至上千条时，可在保持 ID 的前提下增加预生成搜索索引和按分类加载。
