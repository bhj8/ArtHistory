# 美术史漫游地图

中文为主、中英对照的交互美术史导航。目前收录 233 个条目、660 幅配图、237 组关联和 23 条学习路线。

包含时代与地域地图、图解词典、多作品图库、搜索筛选、主题路线、收藏及两项对照。全部 233 个条目已有配图，其中 185 个条目支持多图浏览。配图包括作品、建筑、展览现场、工艺记录和 4 幅明确标注的本站学习图解。支持最近阅读、卡片多图预览和大图细节放大。条目在居中宽幅阅读页中打开，桌面并排展示图文，手机上下阅读；缩略图位于大图上方，可同屏逐幅切换。内容覆盖史前至当代及设计、视觉媒介；这是学习导航，并非穷尽的世界美术史。

按 `/` 或 `Ctrl/⌘ + K` 打开快速检索：边打字边列出条目、人物和作品，方向键选择、回车直接打开；空白时显示最近读过。搜索始终覆盖全部条目，并等拼音输入法选完字再查询。225 位人物各有人物页（生卒年、身份、收录作品、相关条目），正文人名和作品图注的作者名都能点进去。时间轴按分类排列全部条目的大致活跃期，点击时代可放大；详情页列出“同一时期的其他地区与领域”，也能一键定位到时间轴。

选中一个时代时，每个视图顶部都有时代导览：一句话概括这一时期，显示本时代与跨时代延续的条目数，并可直接跳到上一或下一时代（键盘 `[` `]`）。全景地图此时按分类列出本时代全部条目的图卡，并标出仍在延续的更早传统；时间轴按屏幕宽度铺满，横跨整个时代的长期传统单独列出。作品图库按作品本身的创作年代归入时代。在搜索框输入 `1500`、`16世纪`、`前5世纪` 或 `1960年代`，可列出当时正在进行的条目、在世的人物和当时的作品，并在时间轴上标出这一年。分类、时代和核心/全部旁的数字都随其他筛选变化；结果为空时会提示哪些时代或范围有内容。

每个条目可以写私人笔记；收藏、笔记和阅读记录可在“收藏”页导出为 JSON 备份，换设备时再导入合并。支持浅色、深色和跟随系统。可添加到手机主屏幕；读过的条目和看过的图片在离线时仍可打开。

42 个核心条目补全地域、人物、三件以上代表作品及历史影响，并精选 3—4 幅配图优先展示。正文概念和人物可以点击跳转；搜索支持中英文别名及相近拼写提示，分别展示条目、人物和作品。可从图库或详情选择两件作品，并排独立缩放、拖动和更换。关闭条目会恢复原列表位置。

## 本地开发

界面仅为 42 个核心条目标注「核心」，其余条目不显示层级标签。可切换核心或全部条目，并按核心优先排序。条目直接展示视觉特征、历史背景、人物与作品和参考资料。筛选范围保存在分享链接中。

要求 Node.js 22 或更高版本。无第三方运行时依赖，无需 `npm install`。

```sh
npm run dev
```

开发命令会先生成 `dist/` 再启动本地预览，修改源文件后重新运行构建并刷新。

打开终端显示的本地地址。由于数据使用 JSON 加载，请通过 HTTP 服务预览，不要双击 `index.html`。

```sh
npm run check    # 检查数据、引用、图片和 JavaScript 语法
npm run build    # 校验后将网站文件输出到 dist/
npm run preview  # 预览 dist/
```

## 文件职责

| 位置                          | 用途                                      |
| ----------------------------- | ----------------------------------------- |
| `index.html`                  | 页面骨架，无内嵌图片或知识数据            |
| `src/main.js`                 | 初始化、状态、交互及详情面板              |
| `src/ui/views.js`             | 地图、目录、图库与路线                    |
| `src/ui/timeline.js`          | 时间轴与同一时期推荐                      |
| `src/ui/era.js`               | 选中时代时的导览条（上一/下一时代、概述） |
| `src/eras.js`                 | 时代年份边界、作品归属时代、年代检索解析  |
| `src/ui/quick-search.js`      | 搜索框下拉快速检索                        |
| `src/ui/person.js`            | 人物页                                    |
| `src/ui/detail.js`            | 详情、多图与对照                          |
| `src/ui/helpers.js`           | 通用图片、链接与转义组件                  |
| `src/content.js`              | 数据加载与索引，兼容 GitHub Pages 子路径  |
| `src/search.js`              | 人物、作品、别名和拼写提示索引            |
| `src/ui/inline-links.js`      | 正文概念与人物跳转                        |
| `src/ui/art-comparison.js`    | 双图选择、独立缩放与拖动                  |
| `data/authors.json`           | 人物中英文名称、常见译名、生卒年与简介    |
| `src/storage.js`              | 本地收藏、浏览记录、笔记与备份            |
| `sw.js`、`manifest.webmanifest` | 离线阅读与添加到主屏幕                  |
| `src/styles/main.css`         | 页面样式与响应式布局                      |
| `data/entries/*.json`         | 按六条线索分别维护知识条目                |
| `data/artworks.json`          | 独立作品 ID、多条目关联、图片、作者与出处 |
| `data/relationships.json`     | 关联节点、关系类型与解释                  |
| `data/routes.json`            | 学习路线及条目顺序                        |
| `data/taxonomy.json`          | 分区和时代定义                            |
| `data/sources.json`           | 已收录的资料来源                          |
| `assets/artworks/*.{webp,svg}`      | 独立图片文件，支持浏览器缓存与按需加载    |
| `scripts/`                    | 零依赖校验、构建与本地预览工具            |
| `.github/workflows/pages.yml` | PR 校验及 main 分支自动发布               |

首页使用轻量目录和独立缩略图；搜索索引在构建时生成，搜索、条目正文与完整出处按需加载。性能对比及维护方法见 [首页加载优化](docs/PERFORMANCE.md)。

新增内容、图片和关系的具体操作见 [内容维护说明](docs/content-guide.md)。

## GitHub Pages

仓库 **Settings → Pages → Source** 选择 **GitHub Actions**。首次启用后，在 Actions 运行 `Validate and deploy Pages`；以后提交到 `main` 会自动校验并发布，校验失败不会部署。PR 只校验，不部署。

在线网址：https://baohongjiang.com/ArtHistory/ 。

## 图片与资料

图片来自 The Metropolitan Museum of Art、Cleveland Museum of Art、国立故宫博物院、南澳艺术馆、中央美院公开作品记录，以及 Wikimedia Commons 的图片档案。已有的 328 张克利夫兰馆藏图片均按馆方 CC0 字段筛选，保存中文标题、原题、作者归属限定、年代、材质、馆藏记录及许可链接。作者、年代、馆藏链接和权利元数据在 `data/artworks.json` 中保留；来源还包括 V&A 与 MoMA 的公开专题。作品与摄影的权利分别处理：Commons 图片保留摄影者、来源、许可链接与转换说明，照片许可不等同于所摄作品的权利。另有明确标注版权保留的馆方作品图；不把可访问图片统一声明为公共领域。本站学习图解不是历史作品，可用 `node scripts/generate-guides.mjs` 重新生成。代码仓库不替图片统一授予许可。

收藏、笔记和阅读记录保存在浏览器本地，不上传服务器；部署域名改变或换设备时，请在“收藏”页导出备份再导入。
